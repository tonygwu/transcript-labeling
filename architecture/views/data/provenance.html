[source-item] Original source and geometry

json · existing · verified

Store: Private dataset files [dataset-files]

Original text and immutable whitespace-token coordinates. Caption headers remain source metadata, not speaker labels.

Where this data travels

  • Private dataset files -> Prepare original speech: Read an existing original item [read-original]
  • Private dataset files -> Validate and save review data: Read source, drafts and owner review state [read-dataset]
  • Private dataset files -> Export labels with their origin: Read original source, drafts and reviewed data [export-inputs]
  • Input to Prepare original speech [source-preparation]
  • Input to Private dataset files [dataset-files]
  • Output from Private dataset files [dataset-files]
  • Input to Export labels with their origin [export-builder]

Fields and constraints

  • key: recording identifier
  • text: exact original string
  • text_sha256: SHA-256 of UTF-8 text
  • token_count and tokens: matching whitespace tokens
  • meta: end-exclusive header ranges
  • segments: original label, header/body token ranges, t_start, nullable t_end

[inference-request] Prepared private request

Format not described in this model · existing · verified

Store: Private inference artifacts [run-artifacts]

All original speech with source-token markers, identity metadata and hashes. The complete request stays local; only its prompt crosses the adapter boundary.

Where this data travels

  • Prepare original speech -> Private inference artifacts: Write the private request [retain-request]
  • Private inference artifacts -> Resolve exact turn starts: Resolve retained response without a model call [offline-resolution]
  • Output from Prepare original speech [source-preparation]
  • Input to Resolve exact turn starts [exact-resolver]
  • Input to Private inference artifacts [run-artifacts]
  • Output from Private inference artifacts [run-artifacts]

Fields and constraints

  • schema_version: 1
  • source: explicit original-text/token/meta allowlist
  • speakers: [{id,description}] and unclear: id
  • speech: [{index,text}]
  • marker_every: positive integer; default 20 speech words
  • anchor_words: positive integer; default 8 exact words
  • prompt, prompt_sha256, request_sha256: reproducible identity

[model-response] Untrusted response with identity evidence

json · existing · verified

Store: Private inference artifacts [run-artifacts]

Exact model response text plus selected-versus-served identity evidence. A CLI model argument alone proves selection only.

Where this data travels

  • Private inference artifacts -> Resolve exact turn starts: Resolve retained response without a model call [offline-resolution]
  • Input to Resolve exact turn starts [exact-resolver]
  • Input to Private inference artifacts [run-artifacts]
  • Output from Private inference artifacts [run-artifacts]

Fields and constraints

  • response: untouched JSON response string
  • requested_model: exact selected model
  • served_model: same model when reported; null when unverified
  • model_identity: reported or unverified
  • transport: optional caller evidence object

[suggestion-bundle] Validated tentative suggestions

json · existing · verified

Store: Private inference artifacts [run-artifacts]

Source-pinned, ordered speech ranges and provenance. These are proposals, never owner actions.

Where this data travels

  • Resolve exact turn starts -> Private inference artifacts: Write the resolved private bundle [retain-offline-bundle]
  • Resolve exact turn starts -> Validate and save review data: Caller explicitly imports or replaces suggestions [attach-bundle]
  • Output from Resolve exact turn starts [exact-resolver]
  • Input to Validate and save review data [review-service]
  • Input to Private inference artifacts [run-artifacts]
  • Output from Private inference artifacts [run-artifacts]

Fields and constraints

  • schema_version: 1
  • text_sha256 and token_count: original source identity
  • ranges: [{start,end,speaker,source:contextual_model}]
  • provenance: method, requested_model, served_model, model_identity, prompt_sha256, request_sha256, response_sha256, run_id; optional transport

[item-drafts] Current and previous draft bundles

Format not described in this model · existing · verified

Store: Private dataset files [dataset-files]

Draft history retains older proposals and their model provenance. It can resolve recorded confirmation hashes but cannot reconstruct missing or merely annotation-level historical links.

Where this data travels

  • Private dataset files -> Validate and save review data: Read source, drafts and owner review state [read-dataset]
  • Validate and save review data -> Private dataset files: Replace draft fields under source and bundle guards [save-drafts]
  • Private dataset files -> Export labels with their origin: Read original source, drafts and reviewed data [export-inputs]
  • Output from Validate and save review data [review-service]
  • Input to Private dataset files [dataset-files]
  • Output from Private dataset files [dataset-files]
  • Input to Export labels with their origin [export-builder]

Fields and constraints

  • suggestions: contextual or imported source-label ranges
  • suggestions_sha256: digest of ranges
  • suggestion_provenance: contextual request/model evidence when present
  • suggestion_history: prior ranges, digest and provenance
  • suggestion_bundle_sha256: response digest of current ranges plus provenance for guarded updates

[review-projection] Browser reading and visible attribution

Format not described in this model · existing · verified

Source tokens, current draft visibility and human overlays drive the reading. History is excluded and blind suggestions are omitted server-side.

Where this data travels

  • Validate and save review data -> Read and correct the conversation: Serve the permitted reading and overlays [show-review]
  • Output from Validate and save review data [review-service]
  • Input to Read and correct the conversation [review-page]

Fields and constraints

  • source token indices and token_kinds
  • current visible suggestions; suggestions_hidden count otherwise
  • original caption intervals and labels
  • human ranges and correction overlays loaded separately
  • reveal: always or after_answer; saved reveal events are owner actions

[human-annotations] Explicit human speaker ranges

json · existing · verified

Store: Private dataset files [dataset-files]

New confirmations retain exact range-level draft hashes. Legacy annotation-level evidence is marked separately; missing historical links remain absent and cannot be reconstructed from draft history.

Where this data travels

  • Private dataset files -> Validate and save review data: Read source, drafts and owner review state [read-dataset]
  • Read and correct the conversation -> Validate and save review data: Save explicit human edits with source and version checks [submit-review]
  • Validate and save review data -> Private dataset files: Write human answers and correction history separately [save-human]
  • Private dataset files -> Export labels with their origin: Read original source, drafts and reviewed data [export-inputs]
  • Input to Validate and save review data [review-service]
  • Input to Private dataset files [dataset-files]
  • Output from Private dataset files [dataset-files]
  • Output from Read and correct the conversation [review-page]
  • Input to Export labels with their origin [export-builder]

Fields and constraints

  • key, text_sha256, token_count: matching source identity
  • ranges: ordered non-overlapping {start,end,speaker,origin}
  • origin: human, model_confirmed, or suggestion_confirmed; historical model_confirmed may refer to imported tags
  • range suggestions_sha256: optional digest of proposed ranges seen at confirmation
  • range suggestion_bundle_sha256: optional digest including model provenance
  • range suggestion_evidence_scope: range for new confirmations; legacy_annotation for historical annotation-level evidence
  • Missing legacy hashes remain absent across later saves; no current bundle is attached retroactively
  • checked_by: assigned by server
  • top-level suggestions_sha256 and suggestion_bundle_sha256: current annotation-save context, not a substitute for per-range provenance
  • answers version: browser stale-write guard

[caption-corrections] Human wording overlays

Format not described in this model · existing · verified

Store: Private dataset files [dataset-files]

Replacement wording is anchored to original speech tokens. Saving adds a revision and history without changing the source or renumbering speaker ranges.

Where this data travels

  • Private dataset files -> Validate and save review data: Read source, drafts and owner review state [read-dataset]
  • Read and correct the conversation -> Validate and save review data: Save explicit human edits with source and version checks [submit-review]

  • Private dataset files -> Export labels with their origin: Read original source, drafts and reviewed data [export-inputs]
  • Input to Validate and save review data [review-service]
  • Input to Private dataset files [dataset-files]
  • Output from Private dataset files [dataset-files]
  • Output from Read and correct the conversation [review-page]
  • Input to Export labels with their origin [export-builder]

Fields and constraints

  • key, text_sha256, token_count: source identity
  • edits: [{start,end,original,replacement}]
  • revision: checked against prior saved value
  • checked_by and updated_at: server-owned
  • history: previous and next edits per saved revision

[attempt-record] Attempt or cache receipt

Format not described in this model · existing · verified

Store: Private inference artifacts [run-artifacts]

Raw outputs survive adapter failure. A completion marker is written only after the response resolves successfully.

Where this data travels

  • Input to Private inference artifacts [run-artifacts]

Fields and constraints

  • identity: request_sha256, explicit model, adapter argv
  • attempt record: attempt, exit_code, error category/message, stdout and stderr paths
  • success marker: identity and raw_response path
  • status: attempted, succeeded, failed, cached, errors
  • status: running, succeeded or failed; raw filenames reserve attempt numbers even after interruption

[export-document] Portable review export

Format not described in this model · existing · verified

Exports distinguish human decisions from optional tentative filling, preserving per-range evidence hashes and whether that evidence is range-level or only legacy annotation-level.

Where this data travels

  • Export labels with their origin -> Validate and save review data: Return the provenance-preserving export [return-export]
  • Output from Export labels with their origin [export-builder]

Fields and constraints

  • schema_version: 1; tool, project, dataset, kind, no_text
  • data or named export kinds for all
  • suggestions export: current bundle and history
  • segment pieces: source offsets, speaker, origin; optional suggestion_source and suggestions_sha256
  • no_text: removes transcript and free-form provenance
  • confirmed range/piece: optional suggestions_sha256 and suggestion_bundle_sha256
  • suggestion_evidence_scope: range or legacy_annotation; missing history is not inferred
  • Adjacent human pieces with different evidence remain separate

[export-options] Export selection

json · existing · verified

Caller selects export kind, text omission, and optional suggestion filling.

Where this data travels

Fields and constraints

  • kind: spans, segments, focus, corrections, labels, notes, suggestions, or all
  • no_text: boolean
  • fill: absent or suggestions
